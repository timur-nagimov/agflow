# M1c: Web UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the web UI the hub serves. In it, people:
- sign in;
- watch a live board of tasks;
- act on tasks: create, accept, reject, mark merged, unblock, release a claim, cancel;
- edit the goal with a diff preview;
- see the agents and steer the lead and agents by message;
- add and remove standing rules, and search;
- follow a live timeline.

**Architecture:**
- **Stack.** `packages/web` is a React 19 single-page app. A small script, `build.ts`, bundles it with Bun's HTML bundler. Bun is used instead of Vite, which needs Node 20; the project runs on Bun only.
- **Serving.** The hub already serves the build folder when `AGFLOW_WEB_DIST` points to it.
- **Routing.** Routes live in the URL hash (`#/task/T-12`), so the page is always `/` and relative asset paths always resolve.
- **Data.**
  - Plain `fetch` calls go to the hub's REST API, with the session cookie.
  - One `EventSource` follows `/api/events/stream`. Views reload their data when a relevant event arrives; a burst of events causes one reload.
  - The timeline shows the events themselves.
- **Logic.** Rules that are easy to get wrong live in DOM-free modules (`route.ts`, `format.ts`, `api.ts`) with unit tests. They cover board columns, which actions fit which status, how events read as sentences, and request building. Views stay thin.
- **Checks.** `scripts/check-ui.ts` drives the built UI in headless Chromium and checks every flow. It runs against a demo hub seeded with a made-up project.

**Tech Stack:** React 19.3.1, Bun 1.3.11 (bundler and test runner), TypeScript 5.9.3, plain CSS with custom properties (light and dark), fonts from pinned @fontsource packages, playwright-core 1.64.1 for the browser check.

**Depends on:** plan M1a. Tasks 1–12 need only `packages/core` and can run as soon as it exists. Tasks 13–16 need the hub from M1a.

**Spec:** `docs/superpowers/specs/2026-10-26-agflow-design.md`: §7.4 (editing the goal), §7.5 (steering), §10 (web UI) and M1 in §16.

## Design

The UI is a mission log for a team of agents: calm, dense and easy to scan for long stretches.
- **Surfaces.** Light mode is warm paper and ink with a faint graph-paper grid. Dark mode is a warm near-black "night shift". The mode follows the system setting.
- **Type.**
  - Literata, a book serif with Cyrillic, for page titles and the goal. The goal reads like a charter.
  - IBM Plex Sans for the interface.
  - IBM Plex Mono for ids, times, statuses and readouts.
- **Colour.** One signal-orange accent marks primary actions, focus and the current page. Statuses never use the accent. They use six tones: waiting (blue), active (amber), in review (teal), done (green), trouble (red) and closed (grey).
- **Signature elements.**
  - A sticky top strip of live readouts: goal version, tasks per column and active agents, with a progress bar segmented by status.
  - Status lamps for agents and for the live connection.
  - The goal set as a charter, with the lead's interpretation notes in the margin.
- **Motion.** Pages rise in with a short stagger. Events and messages that arrive live flash once. Lamps pulse. `prefers-reduced-motion` turns all of it off.

## Decisions

1. **Bun's bundler and hash routing, no dev server.** `bun run build:web` takes well under a second. To work on the UI, rebuild and reload the page that `bun run demo` serves.
2. **Fonts are copied, not inlined.** Bun 1.3's CSS bundler inlines every `url()` asset, which made the stylesheet 1.9 MB. `build.ts` instead copies the woff2 files of the Latin and Cyrillic subsets into `dist/fonts`, with their own stylesheet.
3. **`"sideEffects": false` in `@agflow/core`.** Without it the bundle keeps zod, because `index.ts` re-exports the schemas. With it the bundle drops from 0.66 MB to 0.26 MB.
4. **Priority 0 is the most urgent.** Neither the spec nor M1a said which way priority runs. The board sorts by it, and the task schema now describes it, so the lead's tools say the same.
5. **Live updates.**
   - On load, the UI asks for the newest event (`GET /api/events?latest=1&limit=1`) and streams from there, so nothing is replayed.
   - After an error it reconnects from the last event it saw.
   - The hub sends a `ready` event as soon as a stream opens. Bun sends a streaming response's headers only with its first bytes, and browsers report the connection open only then.
6. **Knowledge in M1** is the standing rules, which people can remove, plus search over tasks, messages and the goal. Decisions, learnings and research arrive with M4.
7. **Messages to people** appear on the Goal page. The Goal item in the navigation shows how many are new to this browser; that state lives in `localStorage`.
8. **People's task actions** are create, accept, reject, mark merged, unblock, release a claim and cancel. In M1, amending a task's contract stays with the lead.
9. **The hub's error messages are shown as they come.** Every action shows the hub's message when it fails. The goal editor keeps the version it started from, so if someone else saves first, the hub refuses the save instead of overwriting.

## Conventions for every task

- Run all commands from the repository root. Use Bun only; Node on this machine is v16.
- `route.ts`, `format.ts` and `api.ts` must not use `window`, `document`, `localStorage` or other DOM APIs. The root config typechecks their tests and has no DOM types.
- UI text is plain and short. Use "people", "lead", "agent", "task" and "goal". Avoid jargon such as "principal"; the word "lease" appears only where a task shows how long its claim lasts.
- Views have no unit tests. `check:ui` in Task 15 checks their behaviour; until then, each view task ends with the typecheck and the unit tests.
- Commit at the end of each task with the message shown and the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` as a second `-m`. The repository's git identity is preconfigured; do not change it.
- A security hook may refuse to write files whose content looks like shell execution. The code in this plan avoids those patterns; for example, it never calls a regex's `exec` method.

- [ ] **Step 4: Create `packages/web/build.ts`**

```ts
/**
 * Builds the web UI into dist/, which the hub serves when AGFLOW_WEB_DIST points at it.
 *
 * Bun's CSS bundler inlines every url() asset, which would put all fonts into the stylesheet. So the
 * fonts are copied into dist/fonts with their own stylesheet, and index.html links to it after the
 * bundle is written. Only Latin and Cyrillic subsets are kept; other scripts use fallback fonts.
 */
import { copyFileSync, mkdirSync, readFileSync, rmSync, writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';

const root = import.meta.dir;
const dist = join(root, 'dist');

const FONT_STYLESHEETS = [
  '@fontsource/ibm-plex-sans/400.css',
  '@fontsource/ibm-plex-sans/500.css',
  '@fontsource/ibm-plex-sans/600.css',
  '@fontsource/ibm-plex-mono/400.css',
  '@fontsource/ibm-plex-mono/500.css',
  '@fontsource-variable/literata/opsz.css',
  '@fontsource-variable/literata/opsz-italic.css',
];
const SKIPPED_SUBSETS = /-(greek|greek-ext|vietnamese)-/;

function copyFonts(): number {
  const out = join(dist, 'fonts');
  mkdirSync(out, { recursive: true });
  const rules: string[] = [];
  for (const spec of FONT_STYLESHEETS) {
    const stylesheet = Bun.resolveSync(spec, root);
    for (const rule of readFileSync(stylesheet, 'utf8').match(/@font-face\s*{[^}]*}/g) ?? []) {
      const woff2 = rule.match(/url\(\.\/files\/([^)]+?\.woff2)\)\s*format\(([^)]+)\)/);
      if (!woff2 || SKIPPED_SUBSETS.test(woff2[1] as string)) continue;
      const [, file, format] = woff2 as [string, string, string];
      copyFileSync(join(dirname(stylesheet), 'files', file), join(out, file));
      rules.push(rule.replace(/src:[^;]+;/, `src: url(./${file}) format(${format});`));
    }
  }
  writeFileSync(join(out, 'fonts.css'), `${rules.join('\n')}\n`);
  return rules.length;
}

rmSync(dist, { recursive: true, force: true });
const result = await Bun.build({
  entrypoints: [join(root, 'index.html')],
  outdir: dist,
  minify: true,
  define: { 'process.env.NODE_ENV': JSON.stringify('production') },
});
if (!result.success) {
  for (const log of result.logs) console.error(log);
  process.exit(1);
}
const fonts = copyFonts();
const indexFile = join(dist, 'index.html');
writeFileSync(
  indexFile,
  readFileSync(indexFile, 'utf8').replace('</head>', '<link rel="stylesheet" href="./fonts/fonts.css"></head>'),
);
for (const output of result.outputs) console.log(`${output.path.slice(dist.length + 1)}  ${(output.size / 1024).toFixed(1)} KB`);
console.log(`fonts/  ${fonts} font faces`);
```

import { TARGET_PATTERN } from '@agflow/core';

export type Route =
  | { view: 'board' }
  | { view: 'goal' }
  | { view: 'task'; id: string }
  | { view: 'agents' }
  | { view: 'messages'; to?: string }
  | { view: 'timeline' }
  | { view: 'knowledge' };

export type NavView = Exclude<Route['view'], 'task'>;

export const NAV: { view: NavView; label: string }[] = [
  { view: 'board', label: 'Board' },
  { view: 'goal', label: 'Goal' },
  { view: 'agents', label: 'Agents' },
  { view: 'messages', label: 'Messages' },
  { view: 'timeline', label: 'Timeline' },
  { view: 'knowledge', label: 'Knowledge' },
];

const TASK_ID = /^T-\d+$/;

/** Reads a route from a location hash such as "#/task/T-12" or "#/messages?to=lead". */
export function parseRoute(hash: string): Route {
  const [path = '', search = ''] = hash.replace(/^#/, '').split('?', 2);
  const [view, id = ''] = path.split('/').filter(Boolean);
  switch (view) {
    case 'goal':
    case 'agents':
    case 'timeline':
    case 'knowledge':
      return { view };
    case 'messages': {
      const to = new URLSearchParams(search).get('to');
      return to && TARGET_PATTERN.test(to) ? { view, to } : { view };
    }
    case 'task':
      return TASK_ID.test(id) ? { view, id } : { view: 'board' };
    default:
      return { view: 'board' };
  }
}

export function routeHref(route: Route): string {
  switch (route.view) {
    case 'task':
      return `#/task/${route.id}`;
    case 'messages':
      return route.to ? `#/messages?to=${encodeURIComponent(route.to)}` : '#/messages';
    default:
      return `#/${route.view}`;
  }
}

/** The navigation entry to highlight: a task page belongs to the board. */
export function navViewOf(route: Route): NavView {
  return route.view === 'task' ? 'board' : route.view;
}

/** "user:alice" → "alice", "agent:A-3" → "A-3", "system" → "agflow". */
export function who(actor: string): string {
  if (actor === 'system') return 'agflow';
  const colon = actor.indexOf(':');
  return colon === -1 ? actor : actor.slice(colon + 1);
}

export type ActorKind = 'person' | 'agent' | 'system';

export function actorKind(actor: string): ActorKind {
  if (actor.startsWith('user:')) return 'person';
  if (actor.startsWith('agent:')) return 'agent';
  return 'system';
}

export function targetLabel(to: string): string {
  if (to === 'lead') return 'the lead';
  if (to === 'all') return 'everyone';
  if (to === 'humans') return 'people';
  if (to.startsWith('task:')) return `${to.slice(5)} thread`;
  return who(to);
}

export interface TargetOption {
  value: string;
  label: string;
}

/** Who a person can write to: the lead, everyone, people, connected agents and open task threads. */
export function targetOptions(agents: Agent[], tasks: Task[], current?: string): TargetOption[] {
  const options: TargetOption[] = [
    { value: 'lead', label: 'The lead' },
    { value: 'all', label: 'Everyone' },
    { value: 'humans', label: 'People' },
    ...agents
      .filter((agent) => agent.status !== 'gone')
      .map((agent) => ({
        value: `agent:${agent.id}`,
        label: `${agent.id} · ${agent.user}${agent.role === 'lead' ? ' · lead' : ''}${agent.label ? ` · ${agent.label}` : ''}`,
      })),
    ...tasks
      .filter((task) => !isClosed(task.status))
      .map((task) => ({ value: `task:${task.id}`, label: `${task.id} thread · ${clipText(task.title, 48)}` })),
  ];
  if (current && !options.some((option) => option.value === current)) {
    options.push({ value: current, label: targetLabel(current) });
  }
  return options;
}

/** True when a message belongs to the conversation with a target. */
export function inConversation(message: Message, target: string, leadId: string | null): boolean {
  if (target === 'everything' || message.to === target) return true;
  if (target === 'lead') return leadId !== null && message.from === `agent:${leadId}`;
  if (target.startsWith('agent:')) return message.from === target;
  if (target.startsWith('task:')) return message.taskId === target.slice(5);
  return false;
}

export function deliveryLabel(message: Message & Partial<Pick<MessageView, 'deliveries'>>): string {
  const deliveries = message.deliveries;
  if (!deliveries || message.to === 'humans') return '';
  if (deliveries.length === 0) return 'Not delivered yet';
  const read = deliveries.filter((delivery) => delivery.ackedAt !== null).map((delivery) => delivery.agentId);
  const unread = deliveries.filter((delivery) => delivery.ackedAt === null).map((delivery) => delivery.agentId);
  const parts = [read.length > 0 ? `read by ${read.join(', ')}` : '', unread.length > 0 ? `delivered to ${unread.join(', ')}` : ''];
  const text = parts.filter(Boolean).join(' · ');
  return text.charAt(0).toUpperCase() + text.slice(1);
}

/** One plain sentence per event, for the timeline and task histories. */
export function describeEvent(event: HubEvent): string {
  const by = who(event.actor);
  const on = event.subject ?? '';
  const d = event.data;
  switch (event.type) {
    case 'task.created':
      return `${by} created ${on} “${text(d.title)}”`;
    case 'task.updated':
      return `${by} changed ${on}${Array.isArray(d.fields) ? ` (${d.fields.join(', ')})` : ''}`;
    case 'task.claimed':
      return `${by} claimed ${on}`;
    case 'task.working':
      return `${by} started work on ${on}`;
    case 'task.progress':
      return `${by} on ${on}: ${text(d.note)}`;
    case 'task.handoff_written':

const MINUTE = 60_000;

export function ago(ts: number, now: number): string {
  const elapsed = Math.max(0, now - ts);
  if (elapsed < 45_000) return 'just now';
  if (elapsed < HOUR) return `${Math.max(1, Math.floor(elapsed / MINUTE))} min ago`;
  if (elapsed < DAY) return `${Math.floor(elapsed / HOUR)} h ago`;
  return `${Math.floor(elapsed / DAY)} d ago`;
}

/** A short duration such as "1 h 20 min" or "3 d 4 h". */
export function duration(ms: number): string {
  const minutes = Math.max(0, Math.round(ms / MINUTE));
  if (minutes < 60) return `${minutes} min`;
  const hours = Math.floor(minutes / 60);
  if (hours < 24) return minutes % 60 ? `${hours} h ${minutes % 60} min` : `${hours} h`;
  const days = Math.floor(hours / 24);
  return hours % 24 ? `${days} d ${hours % 24} h` : `${days} d`;
}

function queryString(params: Record<string, string | number | boolean | undefined>): string {
  const search = new URLSearchParams();
  for (const [key, value] of Object.entries(params)) {
    if (value === undefined || value === false || value === '') continue;
    search.set(key, value === true ? '1' : String(value));
  }
  const text = search.toString();
  return text ? `?${text}` : '';
}

/** The hub's REST API. `onUnauthorized` runs when the session has ended. */
export function createApi(fetchFn: FetchFn, onUnauthorized: () => void = () => {}) {
  async function request<T>(method: string, path: string, body?: unknown): Promise<T> {
    const response = await fetchFn(path, {
      method,
      headers: body === undefined ? undefined : { 'content-type': 'application/json' },
      body: body === undefined ? undefined : JSON.stringify(body),
    });
    const raw = await response.text();
    let json: unknown = null;
    try {
      json = raw ? JSON.parse(raw) : null;
    } catch {
      json = null;
    }
    if (!response.ok) {
      if (response.status === 401) onUnauthorized();
      const error = (json ?? {}) as { error?: string; message?: string };
      throw new ApiError(response.status, error.error ?? 'http_error', error.message ?? `${method} ${path} failed (${response.status})`);
    }
    return json as T;
  }

  return {
    authConfig: () => request<AuthConfig>('GET', '/api/auth-config'),
    me: () => request<Me>('GET', '/api/me'),
    signOut: () => request<{ ok: true }>('POST', '/auth/logout'),

    status: () => request<HubStatus>('GET', '/api/status'),
    setPaused: (paused: boolean) => request<Project>('POST', '/api/project/pause', { paused }),

    goal: () => request<GoalState>('GET', '/api/goal'),
    goalHistory: async () => (await request<{ versions: GoalVersion[] }>('GET', '/api/goal/history')).versions,
    goalDiff: async (from: number, to: number) =>
      (await request<{ lines: DiffLine[] }>('GET', `/api/goal/diff${queryString({ from, to })}`)).lines,
    saveGoal: (text: string, baseVersion: number) => request<GoalVersion>('PUT', '/api/goal', { text, baseVersion }),

    tasks: async () => (await request<{ tasks: Task[] }>('GET', '/api/tasks')).tasks,
    task: (id: string) => request<TaskDetail>('GET', `/api/tasks/${encodeURIComponent(id)}`),
    createTask: async (input: NewTaskInput) => {
      const { tasks } = await request<{ tasks: Task[] }>('POST', '/api/tasks', { tasks: [input] });
      return tasks[0] as Task;
    },
    taskAction: async (id: string, action: TaskAction, body: Record<string, string>) =>
      (await request<{ task: Task }>('POST', `/api/tasks/${encodeURIComponent(id)}/${TASK_ACTIONS[action].path}`, body)).task,

    agents: async () => (await request<{ agents: Agent[] }>('GET', '/api/agents')).agents,

    messages: async (query: MessageQuery = {}) =>
      (await request<{ messages: MessageView[] }>('GET', `/api/messages${queryString(query)}`)).messages,
    sendMessage: async (message: NewMessage) =>
      (await request<{ message: Message }>('POST', '/api/messages', message)).message,
    rules: async () => (await request<{ rules: Message[] }>('GET', '/api/rules')).rules,
    removeRule: (id: number) => request<{ ok: true }>('DELETE', `/api/rules/${id}`),

    events: async (query: EventQuery = {}) =>
      (await request<{ events: HubEvent[] }>('GET', `/api/events${queryString(query)}`)).events,
    search: (q: string) => request<SearchResult>('GET', `/api/search${queryString({ q })}`),
  };
}

import type { HubEvent } from '@agflow/core';
import { type ReactNode, createContext, useContext, useEffect, useState } from 'react';
import { api } from './api';

type Listener = (event: HubEvent) => void;

const listeners = new Set<Listener>();

/** Runs `listener` for every live event until the returned function is called. */
export function subscribe(listener: Listener): () => void {
  listeners.add(listener);
  return () => {
    listeners.delete(listener);
  };
}

export type Connection = 'connecting' | 'live' | 'reconnecting';

const ConnectionContext = createContext<Connection>('connecting');
const RecentContext = createContext<HubEvent[]>([]);

export const RECONNECT_MS = 3000;
const KEEP_RECENT = 500;

/**
 * Keeps one Server-Sent Events connection to the hub. It starts after the newest stored event, so
 * nothing is replayed when the page opens, and it reconnects from the last event it saw.
 */
export function LiveProvider({ children }: { children: ReactNode }) {
  const [connection, setConnection] = useState<Connection>('connecting');
  const [recent, setRecent] = useState<HubEvent[]>([]);

  useEffect(() => {
    let source: EventSource | null = null;
    let retry: ReturnType<typeof setTimeout> | undefined;
    let lastId = 0;
    let stopped = false;

    const open = () => {
      if (stopped) return;
      source = new EventSource(`/api/events/stream?after=${lastId}`);
      source.onopen = () => setConnection('live');
      source.addEventListener('hub', (message) => {
        const event = JSON.parse((message as MessageEvent<string>).data) as HubEvent;
        if (event.id <= lastId) return;
        lastId = event.id;
        setRecent((list) => [event, ...list].slice(0, KEEP_RECENT));
        for (const listener of listeners) listener(event);
      });
      source.onerror = () => {
        source?.close();
        setConnection('reconnecting');
        retry = setTimeout(open, RECONNECT_MS);
      };
    };

    api
      .events({ latest: true, limit: 1 })
      .then((events) => {
        lastId = events[0]?.id ?? 0;
      })
      .catch(() => {})
      .finally(open);

    return () => {
      stopped = true;
      clearTimeout(retry);
      source?.close();
    };
  }, []);

  return (
    <ConnectionContext.Provider value={connection}>
      <RecentContext.Provider value={recent}>{children}</RecentContext.Provider>
    </ConnectionContext.Provider>
  );
}

export function useConnection(): Connection {
  return useContext(ConnectionContext);
}

export function useRecentEvents(): HubEvent[] {
  return useContext(RecentContext);

/** The current time, refreshed every `intervalMs` so relative times stay right. */

export interface Loaded<T> {
  data: T | undefined;
  error: Error | null;
  reload: () => void;
}

export interface LoadOptions {
  /** Reload when a live event passes this test. Without it, live events are ignored. */
  relevant?: (event: HubEvent) => boolean;
  /** Also reload on a timer, for values that change with time alone. */
  refreshMs?: number;
}

const RELOAD_DELAY_MS = 250;

/**
 * Loads data when `deps` change, then reloads it after relevant live events (a burst of events
 * causes one reload) and on the optional timer. Stale data stays visible while reloading.
 */
export function useData<T>(load: () => Promise<T>, deps: DependencyList, options: LoadOptions = {}): Loaded<T> {
  const [data, setData] = useState<T>();
  const [error, setError] = useState<Error | null>(null);
  const [tick, setTick] = useState(0);
  const loadRef = useRef(load);
  loadRef.current = load;
  const relevantRef = useRef(options.relevant);
  relevantRef.current = options.relevant;

  useEffect(() => {
    setData(undefined);
    setError(null);
  }, deps);

  useEffect(() => {
    let cancelled = false;
    loadRef.current().then(
      (value) => {
        if (cancelled) return;
        setData(value);
        setError(null);
      },
      (caught: unknown) => {
        if (!cancelled) setError(caught instanceof Error ? caught : new Error(String(caught)));
      },
    );
    return () => {
      cancelled = true;
    };
  }, [...deps, tick]);

  useEffect(() => {
    let timer: ReturnType<typeof setTimeout> | undefined;
    const unsubscribe = subscribe((event) => {
      if (!relevantRef.current?.(event)) return;
      clearTimeout(timer);
      timer = setTimeout(() => setTick((n) => n + 1), RELOAD_DELAY_MS);
    });
    return () => {
      unsubscribe();
      clearTimeout(timer);
    };
  }, []);

  useEffect(() => {
    if (!options.refreshMs) return;
    const timer = setInterval(() => setTick((n) => n + 1), options.refreshMs);
    return () => clearInterval(timer);
  }, [options.refreshMs]);

  const reload = useCallback(() => setTick((n) => n + 1), []);
  return useMemo(() => ({ data, error, reload }), [data, error, reload]);
}

export interface Action {
  busy: boolean;
  error: string | null;
  /** Runs a hub call, keeping its error for display. Resolves to null when it failed. */
  run<T>(fn: () => Promise<T>): Promise<T | null>;
  clearError(): void;
}

export function useAction(): Action {
  const [busy, setBusy] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const run = useCallback(async <T>(fn: () => Promise<T>): Promise<T | null> => {
    setBusy(true);
    setError(null);
    try {
      return await fn();
    } catch (caught) {
      setError(caught instanceof Error ? caught.message : String(caught));
      return null;
    } finally {
      setBusy(false);
    }
  }, []);
  const clearError = useCallback(() => setError(null), []);
  return useMemo(() => ({ busy, error, run, clearError }), [busy, error, run, clearError]);
}

  );
